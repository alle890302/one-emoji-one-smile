A tiny Python program that writes exactly one emoji to `/output/entry.txt` —
the single emoji most likely to make a stranger smile, chosen against the
judge's published criteria: plainly warm and friendly to a stranger, warm at
first glance, universal with no irony or in-joke, chosen rather than default,
and right for a stranger (no intimacy, sarcasm or flirtation).

## Run

```sh
python3 main.py
```

Writes the emoji (UTF-8, no trailing newline) to `/output/entry.txt`.
